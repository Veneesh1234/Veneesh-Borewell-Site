SUPPORT & TROUBLESHOOTING:
==================================================

Issue: Server won't start
→ Solution: Check if port 8000 is available
           Try: python -m http.server 9000

Issue: QR Code not showing
→ Solution: Ensure upi-qr-code.png is in folder
           Refresh browser (Ctrl+F5)

Issue: UPI payment not opening
→ Solution: Install UPI app (Google Pay, PhonePe)
           Try direct UPI link: upi://pay?pa=...

Issue: WhatsApp not opening
→ Solution: Have WhatsApp installed/web version
           Check phone number format
