TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

❌ Page won't load?
   → Check server is running
   → Try: http://127.0.0.1:8000

❌ Payment buttons don't work?
   → Have UPI app installed (Google Pay, PhonePe, etc.)
   → Check WhatsApp is installed/web version accessible

❌ QR Code not showing?
   → Upload upi-qr-code.png to website folder
   → Clear browser cache (Ctrl+Shift+Del)
   → Refresh page (Ctrl+F5)
