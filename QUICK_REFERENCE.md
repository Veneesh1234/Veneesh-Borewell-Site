## ⚙️ Customization

### Change Product Price
Edit `index.html`:
```html
<!-- Find this: -->
<button onclick="addToCart('C.R.I Pumps', 25000)">Buy Now</button>

<!-- Change to: -->
<button onclick="addToCart('C.R.I Pumps', 30000)">Buy Now</button>
```

### Change Delivery Fee
Edit `script.js`:
```javascript
// Find this:
const delivery = 500;

// Change to:
const delivery = 1000;
```

