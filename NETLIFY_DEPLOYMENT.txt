TROUBLESHOOTING DEPLOYMENT
═══════════════════════════════════════════════════════════════════════════════

❌ Issue: "Website not found"
   → Solution: Wait 60 seconds for deployment
             → Check Netlify dashboard for errors
             → Try redeploying

❌ Issue: "Images not loading"
   → Solution: Check image file names (case-sensitive)
             → Ensure files uploaded to Netlify
             → Verify correct file paths in HTML

❌ Issue: "Payment buttons don't work"
   → Solution: Check WhatsApp phone number format
             → Verify UPI ID is correct
             → Test on mobile with UPI app installed

❌ Issue: "QR Code not showing"
   → Solution: Upload upi-qr-code.png file
             → Clear browser cache (Ctrl+Shift+Del)
             → Hard refresh (Ctrl+F5)
